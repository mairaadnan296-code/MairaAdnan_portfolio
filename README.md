# 🌐 Maira Adnan Portfolio Website

A modern, responsive, and professional portfolio website developed using **HTML, CSS, and JavaScript**. This project showcases my skills, projects, and contact information in a clean and user-friendly interface.

This portfolio website was created as part of my **Software Development Internship (Frontend Development)**.

The website includes:

- 🏠 Home Section

- 💼 Projects
- 📞 Contact Section
- 📱 Responsive Design
- 🎨 Modern UI Design
- 🍔 Mobile Navigation Menu
- ✨ Smooth Scrolling Effects
